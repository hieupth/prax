# Prax

A minimal agent harness written in Rust, built on [cordis-rs](https://github.com/dshbox/cordis-rs), with a plugin model borrowed from DeepSeek's harness.

## Why this name, Prax?

Prax is short for **praxis**, the medical term for the ability to plan and perform skilled, purposeful action — the bridge between intent and movement. An agent harness does the same job: turning a stated goal into coordinated execution. (In medicine, losing that faculty is called *apraxia* — a harness without Prax.)
